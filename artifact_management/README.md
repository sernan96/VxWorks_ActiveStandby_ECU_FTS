# Artifact Management

V-Model 산출물의 기준선, 변경 이력, 리뷰 기록, 릴리스, 검증 증거를 관리한다.

## 폴더

| 경로 | 내용 |
| --- | --- |
| `baselines/` | 요구사항, 설계, 테스트 산출물 기준선 |
| `reviews/` | 리뷰 회의록, 검토 의견, 조치 내역 |
| `releases/` | 릴리스 패키지, 릴리스 노트, 빌드 정보 |
| `evidence/` | 테스트 로그, 스크린샷, 측정 결과, 검증 증거 |
| `safety_case/` | ISO 26262-inspired safety argument, assumption, evidence 연결 |
| `templates/` | 요구사항, 테스트, 리뷰 문서 템플릿 |

## 관리 대상

- 사용자 요구사항 명세서
- 시스템 요구사항 명세서
- 시스템 아키텍처 설계서
- 소프트웨어 요구사항 명세서
- MBD 상태 머신 설계서
- StateSmith 모델 및 생성 코드
- 보드별 소스 코드
- 테스트 계획 및 테스트 결과
- 변경 이력 및 의사결정 기록
- Validation 증거
- StateSmith 모델 원본 및 생성 코드 기준선
- ISO 26262-inspired safety work product
