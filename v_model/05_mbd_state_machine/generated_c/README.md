# Generated C

StateSmith에서 생성한 C 코드를 저장한다.

현재 생성 파일:

| 파일 | 생성 원본 |
| --- | --- |
| `FailoverSupervisor.h` | `../statesmith_model/FailoverSupervisor.plantuml` |
| `FailoverSupervisor.c` | `../statesmith_model/FailoverSupervisor.plantuml` |

## 규칙

- 이 폴더의 생성 코드는 직접 수정하지 않는다.
- 변경이 필요하면 `statesmith_model/`의 모델을 수정하고 다시 생성한다.
- 생성 코드와 연결되는 VxWorks wrapper는 보드 폴더의 `src/`에서 관리한다.
- 재생성 명령은 `../statesmith_model/StateSmith_Install_And_Generate.md`를 따른다.
