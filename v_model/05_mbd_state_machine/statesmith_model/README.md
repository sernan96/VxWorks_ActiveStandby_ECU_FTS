# StateSmith Model

StateSmith 모델 원본을 저장한다.

## 예정 파일

| 파일 | 목적 |
| --- | --- |
| `FailoverSupervisor.sm` | failover 상태 머신 모델 원본 |
| `FailoverSupervisor.drawio` | draw.io 기반 모델을 사용할 경우의 원본 |
| `StateSmithRunner.csx` | code generation script를 사용할 경우의 실행 스크립트 |

모델 파일명과 생성 방식은 실제 StateSmith 설치 및 사용 방식이 확정되면 갱신한다.
